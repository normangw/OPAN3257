Topics

A preview of the module arc, with a runnable-style example for each stop.

This mirrors the course calendar's module groups (A–H). Each example uses a small imaginary menu, customers, or orders table — the same style of table you'll build live in Colab.

Module A · Foundations

What data is, why spreadsheets break at scale, and your first SQLite table.

CREATE TABLE menu (
    item_id     INTEGER PRIMARY KEY,
    item_name   TEXT NOT NULL,
    price       REAL NOT NULL,
    category    TEXT
);

Module B · Reading Data with SELECT

SELECT, choosing columns, and WHERE — the core of asking a database a question.

SELECT item_name, price
FROM menu
WHERE category = 'Coffee' AND price < 5;

Module C · Multiple Conditions & Text/Math Functions

Combining filters with AND/OR, cleaning text, and doing arithmetic in a query.

SELECT
    UPPER(item_name) AS item,
    price,
    ROUND(price * 1.06, 2) AS price_with_tax
FROM menu
WHERE price >= 3 OR category = 'Bakery';

Module D · Writing & Changing Data

INSERT, UPDATE, DELETE — and why the WHERE clause is a safety device.

INSERT INTO menu (item_id, item_name, price, category)
VALUES (101, 'Cold Brew', 4.25, 'Coffee');

UPDATE menu SET price = 4.50 WHERE item_id = 101;

Module E · Connecting Tables: JOINs

The big idea of the course: linking related tables together.

SELECT c.customer_name, o.order_id, o.order_total
FROM customers AS c
INNER JOIN orders AS o
    ON c.customer_id = o.customer_id
ORDER BY o.order_total DESC;

Module F · Summarizing Data

GROUP BY, HAVING, aggregate functions, sorting and limiting — the manager's SQL behind every KPI dashboard.

SELECT category, COUNT(*) AS items, AVG(price) AS avg_price
FROM menu
GROUP BY category
HAVING COUNT(*) > 2
ORDER BY avg_price DESC
LIMIT 5;

Module G · Advanced Querying

Three-table joins and subqueries — the pattern you'll reuse directly in the semester project.

SELECT seller_id, AVG(delivery_days) AS avg_delivery
FROM orders
GROUP BY seller_id
HAVING AVG(delivery_days) < (
    SELECT AVG(delivery_days) FROM orders
);

Module H · The Modern Analytics Stack

Importing CSVs, warehouse-grade SQL directly over files with DuckDB, and CASE segmentation.

-- DuckDB, querying a CSV directly — no loading step
SELECT
    customer_id,
    CASE
        WHEN total_spent > 500 THEN 'loyal'
        WHEN total_spent > 100 THEN 'active'
        ELSE 'at-risk'
    END AS segment
FROM read_csv_auto('orders.csv')
GROUP BY customer_id, total_spent;
